# Política de Privacidad para MIGU

**Última actualización:**  16 de septiembre de 2026

Esta Política de Privacidad explica cómo **MIGU** recopila, utiliza y protege la información de los usuarios de Discord.

1. **Información que Recopilamos**
   * **Identificadores de Discord:** ID de usuario, ID de servidor (guild) e ID de canales para procesar comandos.
   * **Datos de Configuración:** Ajustes personalizados del bot dentro de cada servidor (roles, canales de bienvenida, etc.).
   * **Contenido:** No guardamos ni leemos mensajes de texto, excepto los comandos dirigidos explícitamente al bot.

2. **Uso de la Información**
   * La información se utiliza exclusivamente para el funcionamiento de los comandos del bot y personalizar la experiencia en tu servidor.
   * No vendemos ni compartimos datos con terceros.

3. **Almacenamiento y Eliminación de Datos**
   * Los datos se almacenan de forma segura. 
   * Si expulsas a MIGU de tu servidor o solicitas la eliminación de tus datos, puedes contactarnos para borrarlos permanentemente de nuestra base de datos.
